# Photography Reference Guide

Drop photos into the correct paths below and the site will display them automatically — no code changes needed. Save each file as a `.png` or `.jpg` (update the extension in `client/src/data/projects.ts` if you use `.jpg`).

All files live under `client/public/figmaAssets/` in the project. The paths below are written as they appear in the browser (starting with `/figmaAssets/`) — strip the `client/public` prefix when reading URLs.

---

## Recommended dimensions at a glance

| Block type | Rendered size (desktop) | Recommended file size |
|---|---|---|
| **Hero** | Full-viewport-width × 600 px tall | **1440 × 600 px** |
| **Gallery — full row** | ~1280 px wide × 560 px tall | **1280 × 560 px** |
| **Gallery — split wide** (~61 % column) | 760 px wide × 500 px tall | **760 × 500 px** |
| **Gallery — split narrow** (~39 % column) | 480 px wide × 500 px tall | **480 × 500 px** |
| **Next-project teaser** | Full-viewport-width × 320 px tall | **1440 × 320 px** |

All images use `object-cover`, so cropping to the exact ratio matters more than the exact pixel count. Landscape orientation works best for hero and full-row images; either orientation works for split columns.

## How to add photos

1. Export or resize your photo to the recommended dimensions.
2. Save it as a **`.png` file** with the **exact filename** shown above (lowercase, hyphens, no spaces). The filename in the table must match exactly — the site requests those paths verbatim.
3. Place it in the correct `client/public/figmaAssets/project-<folder>/` directory.
4. Refresh the site — the photo replaces the grey placeholder automatically. **No code changes required.**

> **JPEG files:** If you need to use `.jpg` instead of `.png`, update the matching filename in `client/src/data/projects.ts` to end in `.jpg`. That is the only code change ever needed.
