#9 – Contact Page Implementation & Navigation

What & Why

Implement the Contact page based on the approved Figma design and
connect it to the site’s existing navigation.

This page is intended to support conversations about future
opportunities—not freelance project inquiries. Match the approved design
as closely as possible. Do not reinterpret spacing, typography, colors,
or layout. Reuse existing layout and typography components wherever
possible.

Done looks like

-   Create a new /contact route.
-   HOME, WORK, and CONTACT navigation function correctly from every
    page.
-   Contact page visually matches the approved design.
-   Contact form is styled but does not require backend functionality
    (frontend only).
-   Responsive behavior matches the rest of the website.
-   Footer remains consistent with the homepage.

Out of scope

-   Form submission or backend/email integration
-   Form validation beyond basic HTML fields
-   New animations
-   Changes to the homepage or project pages
-   Any redesign or reinterpretation of the approved layout

Implementation

Create a new route: /contact

Update the global navigation: - HOME → / - WORK → /#work - CONTACT →
/contact
